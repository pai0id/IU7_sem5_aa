\ssr{ЗАКЛЮЧЕНИЕ}

В ходе данной лабораторной работы было проведено исследование трудоемкости алгоритмов поиска в массиве.

Были выполнены следующие задачи:
\begin{itemize}
    \item Описаны алгоритмы поиска в массиве полным перебором и бинарного поиска;
    \item Спроектированы необходимые алгоритмы;
    \item Реализовано программное обеспечение;
    \item Проведен сравнительный анализ алгоритмов по трудоемкости.
\end{itemize}
