\ssr{ВВЕДЕНИЕ}

Целью данной лабораторной работы является проведение исследования трудоемкости алгоритмов поиска в массиве. Будут рассмотрены алгоритм поиска перебором и алгоритм бинарного поиска.

Задачи работы:
\begin{itemize}
    \item Описание алгоритмов поиска в массиве полным перебором и бинарного поиска;
    \item Проектирование необходимых алгоритмов;
    \item Реализация программного обеспечения;
    \item Сравнительный анализ алгоритмов по трудоемкости.
\end{itemize}
