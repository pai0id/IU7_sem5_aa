\ssr{ВВЕДЕНИЕ}

Целью данной лабораторной работы является освоение метода оценки трудоемкости алгоритмов. В рамках работы рассматриваются стандартный алгоритм умножения матриц и алгоритм Винограда. Первый представляет собой классический метод, а алгоритм Винограда — оптимизированная версия, снижающая количество операций.

Задачи работы:
\begin{itemize}
    \item Описание алгоритмов умножения матриц — стандартного и Винограда.
    \item Оценка трудоемкости алгоритмов по листингам, включая вычислительные операции (л.с.) и хранимые состояния (х.с.) для алгоритма Винограда и его оптимизированной версии.
    \item Разработка программного обеспечения
    \item Проведение замеров процессорного времени выполнения алгоритмов при изменении линейного размера матриц.
    \item Сравнительный анализ на основе графиков зависимости времени выполнения от размера матриц для исходной и оптимизированной версий алгоритма Винограда.
\end{itemize}
